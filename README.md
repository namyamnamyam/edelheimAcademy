# Edelheim Academy — Erdia World Guide

에르디아 세계관과 에델하임 제국 아카데미를 소개하는 GitHub Pages용 정적 웹사이트입니다.

## 구성
- 세계관 소개
- 에델하임 제국 아카데미
- 설정 사전
- 주요 인물 28명 카드 / 필터 / 상세 모달
- 모바일·태블릿 반응형 UI

## GitHub Pages 공개
별도 빌드가 필요 없는 정적 사이트입니다.

GitHub 저장소에서 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택한 뒤,
**Branch: main / (root)**로 저장하면 공개할 수 있습니다.

예상 주소: `https://namyamnamyam.github.io/edelheimAcademy/`
